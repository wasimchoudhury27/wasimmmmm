# Contributing

Thank you for your interest in improving SCAMSHIELD AI.

## Workflow

1. Read the README and check existing issues.
2. Create a focused branch for your change.
3. Install dependencies with `bun install`.
4. Run `bun run lint` and `bun run build` when applicable.
5. Open a pull request describing the change and how it was tested.

## Guidelines

- Keep changes focused and readable.
- Never commit API keys, credentials, private user data or real scam-victim evidence.
- Keep Gemini credentials server-side.
- Include screenshots for meaningful UI changes.
- Keep AI accuracy claims realistic and evidence-based.
