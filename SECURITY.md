# Security Policy

## Reporting a vulnerability

Please do not publish exploitable vulnerabilities in a public issue. Contact the maintainer through the private contact options on the GitHub profile. Include a concise description, safe reproduction steps, impact and suggested mitigation.

Never include passwords, API keys, OTPs, payment details or personal information in a report.

## Security expectations

- Keep `.env` and real API credentials out of Git.
- Store Gemini API keys in server-side environment secrets only.
- Never commit real user messages, uploaded evidence or personal data.
- Treat AI-generated scam assessments as advisory, not definitive.
